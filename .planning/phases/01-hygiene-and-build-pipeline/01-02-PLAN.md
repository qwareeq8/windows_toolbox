**Create `README.md`** per D-11. Include these sections:

1. **Title and tagline**: "Virelo" with a one-line description: a personal Windows desktop utility that snaps windows to configurable sizes and auto-sizes File Explorer columns.

2. **What it does**: Two core features -- (1) multi-press keyboard shortcut snaps the foreground window to a configurable size/position, (2) auto-sizes File Explorer Detail view columns when navigating folders.

3. **Requirements/constraints**: Windows 10/11 x64 only. Requires administrator privileges (auto-elevates at launch). Personal-use software.

4. **Build from source**: Prerequisites (Python 3.8+, Node.js, Inno Setup 6 for installer). Steps:
   ```
   scripts/bootstrap.ps1        # Create .venv + install Python deps
   scripts/build-frontend.ps1   # Build React frontend
   scripts/build-app.ps1        # PyInstaller -> dist/Virelo/Virelo.exe
   scripts/build-installer.ps1  # Inno Setup -> installer/dist/VireloSetup.exe
   ```

5. **Development mode**: Set `VIRELO_DEV=1` env var. Start Vite dev server (`cd frontend && npm run dev`). Run `python main.py`. Frontend hot-reloads from localhost:5173.

6. **Architecture overview**: Brief description -- Python/PySide6 backend hosts React frontend in QWebEngineView, communicating through QWebChannel.

7. **Status**: Under active development. Current version 1.5.0.

8. **License**: MIT

Do NOT include badges, CI status, contributor guidelines, or other enterprise patterns. This is a personal-use tool.

**Rewrite `CLAUDE.md`** per D-13. The current content is auto-generated by GSD and must be replaced entirely. Structure:

1. **Project**: Brief description of what Virelo is.

2. **Build Commands**: The exact PowerShell commands for each build step (bootstrap, clean, build-frontend, build-app, build-installer, verify-release). Also include dev mode: `$env:VIRELO_DEV=1; cd frontend; npm run dev` then `python main.py`.

3. **Project Structure**: List the key files and their roles:
   - `main.py` -- Application entry point, MainWindow, ShiftSnapRestore
   - `bridge.py` -- QWebChannel bridge (VireloBridge QObject)
   - `webview.py` -- QWebEngineView host
   - `settings.py` / `settings_state.py` -- Settings persistence via QSettings
   - `app_config.py` -- Product metadata, defaults, version (single source of truth)
   - `snap_service.py` -- Snap service facade
   - `explorer_columns.py` -- COM-based Explorer column autosize
   - `workers.py` -- Background QThread workers
   - `frontend/src/` -- React 19 frontend (app.jsx, pages.jsx, panels.jsx, etc.)
   - `scripts/` -- PowerShell build pipeline
   - `installer/virelo.iss` -- Inno Setup installer script
   - `Virelo.spec` -- PyInstaller spec file

4. **Naming Conventions**: Python: `snake_case` for modules/functions, `PascalCase` for classes, `UPPER_SNAKE_CASE` for constants. JS: `camelCase` for functions/variables, `PascalCase` for React components.

5. **Forbidden Changes**: (a) Never reintroduce "Windows Toolbox" or "Toolbox" in any file. (b) Never add fake/placeholder UI controls that don't connect to real backend logic. (c) Never commit `frontend/dist/`, `dist/`, `build/`, `.venv/`, or `__pycache__/` to git. (d) Never hardcode version strings -- use `APP_VERSION` from `app_config.py`.

6. **Known Footguns**: (a) `app_config.py` must not be imported in `Virelo.spec` (use regex). (b) PowerShell `$LASTEXITCODE` must be checked after every external command. (c) Vite `define` values must use `JSON.stringify()`. (d) Inno Setup `#define` must use `#ifndef` guard to allow `/D` override.
