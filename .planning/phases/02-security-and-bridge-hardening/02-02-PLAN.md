<objective>
Restructure the bridge to use a Python-side draft/commit state model: settings changes accumulate in a draft dict, Save persists to QSettings and applies side effects, Discard reverts to persisted values. Standardize all bridge slot return payloads to {ok, data}/{ok, error}. Add setWindowCommand slot for title bar minimize/close.

Purpose: Currently `save_settings` writes to QSettings immediately on every keystroke. The draft model separates UI state from persistence, prevents registry thrashing, and enables clean Save/Discard semantics. Structured payloads enable consistent error handling across all bridge calls.

Output: Modified `settings_state.py` with draft model, `bridge.py` with new slots and standardized responses, `main.py` with window command support.
